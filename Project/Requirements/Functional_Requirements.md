**Functional Requirements**



* Miriam Almimi Contributions:



FR-01: The system should authenticate users and provide access to functions according to their role: student, internship coordinator, academic supervisor, or company supervisor.

FR-02: The system should allow a student to complete and submit an internship application.

FR-03: The system should allow an internship coordinator to review a submitted internship application and update its status to approved or rejected. FR-04: The system should allow an academic supervisor to view the weekly logbooks submitted by students assigned to them.

FR-05: The system should allow the company supervisor to submit a post-internship feedback form evaluating the student's performance after the internship is completed.



* Raghad Diab Contributions



FR-06: The system should allow students to submit a weekly logbook for each internship week. 

FR-07: The system should allow an academic supervisor to review a weekly logbook, add comments, and either approve it or request revision. 

FR-08: The system should generate notifications or reminders for pending actions like missing weekly logbooks, requests for logbook revision, and awaiting academic supervisor review.

FR-09: The system should allow students to submit a feedback form about their internship experience after completing the internship.

FR-10: The system should allow internship coordinators to assign an academic supervisor and a company supervisor to a student. 



* Ahmad Amin Contributions

FR-11: The system shall allow an internship coordinator to create, update, and maintain a student's internship placement record, including the company details, internship position, start date, and end date.

FR-12: The system shall allow a student to view their current internship application and placement status, and their assigned academic and company supervisors.

FR-13: The system shall allow students to upload required internship-related documents and associate them with their internship application or placement record.

FR-14: The system shall display each student's internship progress by showing completed internship weeks and the status of each weekly logbook, such as not submitted, submitted, approved, or revision required.

FR-15: The system shall allow an internship coordinator to filter students based on internship application or placement status, such as submitted, approved, rejected, etc.
