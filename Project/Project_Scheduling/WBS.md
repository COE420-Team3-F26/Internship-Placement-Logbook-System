**Work Breakdown Structure (WBS)**



T1: Requirements Refinement - Finalize the functional and non-functional requirements, scenarios, use cases, user roles, and system scope. 

T2: System and Database Design - Design the overall system structure and database needed for user accounts, internship applications, placements, logbooks, and feedback. 

T3: User Interface Design - Design the main interfaces and navigation for students, internship coordinators, academic supervisors, and company supervisors. 

T4: Authentication and Role Management - Implement user login, password protection, role-based access, and session management for the four user roles.

T5: Internship Application Module - Implement application submission, required and additional document uploads, coordinator review, application status, and student status viewing. 

T6: Placement and Supervisor Module - Implement placement records, company and internship information, academic and company supervisor assignment, filtering, and placement status. 

T7: Weekly Logbook and Notification Module - Implement weekly logbook submission, supervisor review, approval/revision, comments, logbook status tracking, and related notifications. 

T8: Internship Feedback Module - Implement student feedback and company supervisor evaluation, including validation, storage, and submission confirmation after internship completion. 

T9: System Integration - Integrate authentication, applications, placements, logbooks, notifications, feedback, and their shared data so the complete internship workflow operates together. 

T10: System Testing and Defect Resolution - Test the complete system using student, coordinator, academic supervisor, and company supervisor workflows and fix identified problems. 

T11: User Acceptance and Refinement - Conduct final user review, verify that the system satisfies the defined requirements, and make necessary refinements.  

T12: Deployment Preparation and Final Documentation - Prepare the system for delivery, organize the final repository, complete system documentation, and prepare the final demonstration.
