**Project Description:**



Our system is designed to simplify and organize the internship process for students, supervisors, and internship coordinators. The system addresses the need for a centralized platform to manage internship applications, student placements, supervisor assignments, and weekly progress reporting.



The main users of the system are:

* students
* academic supervisors
* internship coordinators
* company supervisors. 



The main features of the system include internship application and placement management, supervisor assignment, weekly logbook submission, progress tracking, and communication between users. The key functionalities allow students to submit applications and weekly reports, coordinators to manage placements and assign supervisors, and supervisors to review, comment on, and approve student submissions.
