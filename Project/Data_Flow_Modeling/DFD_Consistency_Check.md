# DFD Consistency and Balancing Check

The Context Diagram and Level-0 DFD were reviewed to ensure consistency between the external entities, data flows, and system processes.

## External Entities

Both diagrams include the same four external entities:

- Student
- Internship Coordinator
- Academic Supervisor
- Company Supervisor

## Data Flow Consistency

The Level-0 DFD maintains the main inputs and outputs represented in the Context Diagram, including:

- User login credentials and authentication results
- Internship applications, documents, and application status
- Internship placements and supervisor assignments
- Weekly logbook submissions, reviews, and notifications
- Student feedback and company supervisor evaluations

## Processes and Data Stores

The Level-0 DFD divides the system into five main processes:

- P1: Authenticate Users
- P2: Manage Internship Applications
- P3: Manage Placements and Progress
- P4: Manage Logbooks and Notifications
- P5: Manage Feedback

It also includes three internal data stores:

- D1: User Accounts
- D2: Internship Records
- D3: Logbooks and Feedback

## Conclusion

The Level-0 DFD is consistent with the Context Diagram in terms of the main external entities and system interactions. It provides additional detail about the internal processes and data stores without changing the overall system scope.
