**Initial Feasibility Study**



1. Technical Feasibility

Our project is technically feasible because it can be developed using available technologies and skills. The system can be implemented as a web application using web development and programming languages such as HTML, CSS, JavaScript for the front end, Java for the back end, and SQL for the database. GitHub and Git Bash can be used for version control and collaboration. The system does not require specialized hardware or highly advanced technologies. The main technical challenge will be integrating the different modules, maintaining proper role based access, and ensuring that application, placement, and logbook data are stored correctly. 



2\. Economic Feasibility

Our project is economically feasible because the expected development cost is very low. We can use existing personal laptops, university’s available computing and internet facilities, GitHub, development environments, programming frameworks, and open-source database technologies. No specialized equipment or paid software is required for the project prototype.



3\. Operational Feasibility

Our system addresses a genuine need because internship management may involve information scattered across emails, documents, spreadsheets, and communication between several parties. A centralized system would organize internship placements, supervisor assignments, weekly submissions, feedback, and student progress in one place, making the process easier for students, supervisors, and internship coordinators to manage.



4\. Schedule Feasibility

The project is feasible within the course duration because the system can be developed incrementally, with the main features divided into manageable stages. Focusing only on the defined in-scope features and excluding more advanced features will help keep the project achievable within the available time.



5\. Overall Feasibility

Overall, our system is feasible from technical, economic, operational, and schedule perspectives. The required technologies and development skills are available, the expected cost is low because the project mainly relies on existing laptops and free or open source tools, and the system addresses a real problem by centralizing internship related activities in one platform. The main constraints are the limited course duration, possible changes in requirements, and the need to integrate and test the different system increments. These constraints can be managed
