

**Components Descriptions:**



CO1| User \& Access Management| Login, roles, and the actions of each user role.

CO2| Application Management| Internship applications, completeness checks, application status, and documents.

CO3| Placement Management| Placement records for approved applications, and company details.

CO4| Logbook \& Progress Monitoring| Weekly logbooks, review decisions, and internship progress.

CO5| Notification \& Feedback| Notifications/reminders and post-internship feedback.

CO6| Database| Permanent storage of all records (external database system).
